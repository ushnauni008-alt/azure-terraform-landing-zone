# Azure Terraform Landing Zone

This is my hands-on project to practice building Azure infrastructure using Terraform.

## Project Goal

The goal of this project is to understand how Azure infrastructure can be created and managed using Infrastructure as Code instead of creating resources manually.

## What I Have Implemented

- Terraform configuration for Microsoft Azure
- Reusable Terraform modules
- Variables, maps and `for_each`
- Azure Resource Group module
- Terraform remote state using Azure Storage
- Git and GitHub for version control
- Feature branch and Pull Request workflow
- Terraform formatting and validation
- TFLint checks
- Gitleaks for basic secret scanning
-GitHub Actions CI workflow to run Terraform checks on Pull Requests
  
## Repository Structure

- `.github/workflows` - GitHub Actions workflow
- `practice` - Terraform configuration and modules
- `.gitignore` - Files that should not be committed to Git
- `README.md` - Project information

## Tools Used

- Microsoft Azure
- Terraform
- Git
- GitHub
- GitHub Actions
- TFLint
- Gitleaks

## Currently Working On

I am continuing to build this project step by step. The next part is Azure networking, including VNet and subnet configuration using reusable Terraform modules.

## Learning Focus

Through this project, I am practicing Terraform, Azure infrastructure, reusable modules, remote state management, Git workflow and basic infrastructure security.
